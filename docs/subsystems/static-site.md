# 静态站点

`src/` 是可在浏览器里直接打开的复习页，`dist/` 是它的部署副本。学习状态写入 `localStorage`，键名是 `architecture_review_focused_notes_v2`。

`src/storage.js` 的间隔序列与 `REVIEW_INTERVALS` 相同，日历日按 Asia/Shanghai，与 [复习规则](domain.md) 同一天界，模块并不共用。全部题目只列出卡片，展开不揭晓。整卡「揭晓答案」才显示讲解；多空题在选定该空后可以单独揭晓或遮挡该空。揭晓不写入学习记录。今天和接下来的计划各 13 条，多出的写剩余道数。笔记是三个文本槽，至少一槽有文字才能点「今天复习完」，留在这台浏览器。焦点模式用方括号切换填空，揭晓后按 c 标记完成。登录后的复习台沿用同一套揭晓、门槛和按键，并可导入。笔记上限见 [复习规则](domain.md)。
