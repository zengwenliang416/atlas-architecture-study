# 静态站点

`src/` 是可在浏览器里直接打开的复习页，`dist/` 是它的部署副本。学习状态写入 `localStorage`。系统架构设计师的键名是 `architecture_review_focused_notes_v2`，大模型的键名是 `llm_review_focused_notes_v1`。

`src/storage.js` 的间隔序列与 `REVIEW_INTERVALS` 相同，日历日按 Asia/Shanghai，与 [复习规则](domain.md) 同一天界，模块并不共用。填空能否揭晓、对照行和月历格子来自 `src/desk.js`，与 `packages/desk` 同一份纯函数。卡片标记仍由静态页和 React 各画一份。

全部题目只列出卡片，展开不揭晓。整卡「揭晓答案」才显示讲解；多空题在选定该空后可以单独揭晓或遮挡该空。揭晓和未交卷的选择不写入学习记录。

「开始自测」进入焦点队列。作答之后可以「遮挡」，再按「交卷」。对照写在红左边线里，逐空列出选择和正确答案。交卷把每空写成对、错、未答或概念填空，不推进间隔。没有选项的空不作对错。多选题要选中的字母和答案整组一致才算对。判断题与单选题同一判法。「错题」只留下上次交卷里答错或未答的选择题。

论文题在范文上方有草稿。草稿随该题学习记录留在这台浏览器，不改范文。今天和接下来的计划各 13 条，多出的写剩余道数。当月格子按 Asia/Shanghai 计负荷：到期日不晚于今天的题计在今天，更晚的计在到期日。

笔记是三个文本槽，至少一槽有文字才能点「今天复习完」，留在这台浏览器。焦点模式用方括号切换填空，揭晓后按 c 标记完成。登录后的复习台沿用同一套交互，记录在服务器。笔记上限见 [复习规则](domain.md)。
