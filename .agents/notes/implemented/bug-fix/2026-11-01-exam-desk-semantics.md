# Agent Note: 考场揭晓和上海日历两边对齐

Status: implemented

## Problem

静态页和登录后的复习台各自解释「今天」和「全部展开」。静态 `day()` 用浏览器本地日期，复习台和 API 用 Asia/Shanghai。全部展开会把每道题放进揭晓集合，候选还没提交答案就看见正确答案。今天的列表一边全部铺开，一边截到 13 条且不说明剩下多少。窄屏底栏盖住选项，计数却用整库长度。

## Decision

揭晓只来自每题的「揭晓答案」。全部题目只把筛选结果列成卡片，标题在揭晓前不写正确答案。已经揭晓的题保持揭晓。

静态日历日在 `src/storage.js` 用 UTC+8 计算，不引用 `@atlas/domain`。静态页以文件打开，没有工作区包的解析；两边的天界必须相同，所以算法跟 `shanghaiDate` 对齐，加日也不走宿主时区。语义写在 [静态站点](../../../../docs/subsystems/static-site.md) 和 [Web](../../../../docs/subsystems/web.md)。

今天和接下来的计划都先显示 13 条，多出的写「还有 N 道」。静态文案说明记录在这台浏览器，并指向复习台的「导入本机旧记录」。复习台说明记录在服务器。间隔档的文字两边相同。

窄屏主内容留出底栏高度和安全区。底栏的序号和上一题、下一题走当前筛选列表。宽度不超过 720px 时不显示「顶部」。考场配色仍按 [复习界面按考场方向收束](../feature/2026-11-01-unslop-direction.md)。

## Alternatives considered

让静态页直接 import `@atlas/domain`。打开 `dist/index.html` 时没有包解析，复习规则会在浏览器里加载失败。

在静态页做导入按钮，把 localStorage 发给 API。没有登录会话，请求会失败。导入留在已登录的复习台。

底栏改成不悬浮。学习时需要一直能切题，所以仍固定在底部，用内边距把选项让出来。

## Consequences

`packages/bank-architecture` 和 `src/data.js` 没有改。掌握等级、间隔天数和笔记长度仍由原来的规则计算。静态间隔表仍是一份拷贝。

`tests/smoke.mjs` 检查上海午夜、加日，以及窄屏让出底栏且不显示「顶部」。`tests/startup.mjs` 检查全部题目不揭晓，计划列表的剩余道数，以及底栏计数跟筛选后的题数一致。静态站点和 Web 两页要写下这些规则，字数上限分别是 153 和 78。
