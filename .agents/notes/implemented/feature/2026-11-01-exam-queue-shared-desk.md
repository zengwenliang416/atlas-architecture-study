# Agent Note: 交卷队列、错题、草稿和月历

Status: implemented

## Problem

「开始自测」只是把焦点放回第一题。答完没有一次交卷，选择和正确答案不能并排对照。上次答错的空没有留下，目录里也不能只看这些题。论文范文直接铺在第四区，没有一块先写自己的地方。复习计划只有两条 13 项列表，看不出一个月里哪天堆了多少题。静态页和登录后的复习台各画一套题卡，填空状态和对照口径会再次分开。

## Decision

「开始自测」拍下整库队列，清掉揭晓和选择，停在焦点模式。队列里可以作答，也可以「遮挡」而不离开队列。「交卷」用红左边线逐空写出选择和正确答案，并把每空记成对、错、未答或概念填空。没有选项的空记为概念填空，不进入「错题」。答错或未答的选择题才进入「错题」。这次记录写在原有学习记录上，不推进等级、间隔或复习次数。未交卷的选择和揭晓仍然只留在页面里。

论文题在范文上方有一块草稿。静态页把它放进本机学习记录，复习台把它放进服务器上的同一条记录。范文原文不动。

月历只画 Asia/Shanghai 的当月。到期日不晚于今天的题计在今天，更晚的计在各自的到期日。今天和接下来的列表仍各 13 条，多出的写剩余道数。

填空能否揭晓、状态句、对照行、对错判定和月历格子放在 `packages/desk`。`src/desk.js` 与 `dist/desk.js` 是同一份文件。静态页不引用 `@atlas/domain`。筛选里的「错题」在 domain 里也有一份同样的判定，测试锁住两边。卡片的 HTML 和 React 标记仍然各写一份。语义写在 [静态站点](../../../../docs/subsystems/static-site.md)。红边沿用 [复习界面按考场方向收束](./2026-11-01-unslop-direction.md)。整卡揭晓仍见 [考场揭晓和上海日历两边对齐](../bug-fix/2026-11-01-exam-desk-semantics.md) 和 [费曼门槛、换空和按空揭晓](./2026-11-01-feynman-blank-focus.md)。

## Alternatives considered

把静态页和 React 合成一个题卡组件。打开 `dist/index.html` 时没有包解析，整页重写也超过这一轮要动的范围。留下的是纯函数一份、标记两份。

另建尝试表或第二套间隔。错题会变成另一台复习机器。逐空结果放进原有学习记录，交卷不调用完成复习。

只给当前这一题交卷。队列是整份试卷，未作答的选择题记为未答。

把草稿放进揭晓后才显示的第四区。那样要先看见范文才能写。草稿留在遮挡之外，范文仍随整卡揭晓。

静态页直接 import `@atlas/domain`。文件页没有工作区解析。月历和对照放进可复制的纯函数文件。

## Consequences

`packages/bank-architecture` 和 `src/data.js` 没有改。掌握等级、间隔天数和笔记长度仍由原来的规则计算。数据库为学习记录增加交卷文本和论文草稿两列。

`packages/desk` 的测试覆盖对照和月历。`tests/startup.mjs` 覆盖交卷、遮挡、错题筛选、草稿和当月格子，并核对三份 `desk` 文件相同。登录后的复习台没有在浏览器里点过。
