# Agent Note: 背题和批过的卷

Status: implemented

## Problem

复习台只有遮住答案的自测。想先看着正确答案把题过一遍，没有一个不交卷的位置。交卷之后的对照是一行行拼出来的字符串，选项名粘在字母后面，对和错只在句尾出现一个字，手机上不好扫。

## Decision

「背题」和自测、只看题干排在一起。题干、正确选项和讲解同时可见。选择题里答对的选项用红左边线。题库写了「是什么」或「为什么」才显示，HCIP AI 没有这些句子，页面就不编。多选标出全部正确字母。填空写出标准术语。方向键换题。可以按知识域、错题和未记住收窄。

「记住了」是本地标记，键名 `atlas_review_memorized_v1`。静态页的范围是题库标识。登录后的复习台的范围是邮箱加题库标识，因为学习记录上没有一列能只表示「看过答案」而不表示掌握或交卷。它不写 `nextReviewOn`、阶段、复习次数或逐空结果。见 [交卷队列、错题、草稿和月历](./2026-11-01-exam-queue-shared-desk.md)。

交卷仍按原路径写入逐空结果和账本。对照改成批过的卷：一句计数，全部、只看错题、未答三个筛选，每题一行。错用红字，对用弱化色的「对」。错和未答并排写「你选」和「正解」，名字来自题库。错项在题库里有理由时可以展开。点题号回到那一题。没有单独的「错题回炉」队列，错题筛选已经读上次交卷。绿色仍只标已掌握，对的勾不用那一色。见 [复习界面按考场方向收束](./2026-11-01-unslop-direction.md)。

## Alternatives considered

把「记住了」写成掌握等级。等级会和间隔旁边的「已掌握」混成一件事，看答案就变成复习。

给登录用户加一列服务器字段。现有列分别是等级、间隔、笔记、交卷和草稿，没有一列的含义是「只读过」。本地标记不增加第二套间隔。

再做一个错题回炉按钮，把错题抄进另一份队列。错题筛选已经是这份队列。

对的题目用绿色勾。这一套里的绿只表示已掌握。弱化色的「对」和红字的「错」分开。

## Consequences

`packages/bank-architecture`、`packages/bank-hcip` 和 `src/data.js` 没有改。掌握等级、间隔天数和笔记长度仍由原来的规则计算。三份 `desk.js` 仍是同一份文件，批卷的你选、正解和记住了的读写形状在这里。

`packages/desk` 的测试覆盖多选、判断和没有理由的空。`tests/startup.mjs` 覆盖静态页交卷后的你选和正解，以及记住了不改复习次数、阶段和下一次复习。HCIP AI 的背题不出现编造的「是什么」。
