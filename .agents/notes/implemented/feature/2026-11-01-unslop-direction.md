# Agent Note: 复习界面按考场方向收束

Status: implemented

## Problem

系统架构设计师复习产品有两张给人看的脸。静态页用轨道图、全大写眉题和四张等宽指标卡开场。登录后的工作台收成一条顶栏，题目皮肤仍是同一套，揭晓后整段解析铺 `#fbda83`。题干、选项、口诀和论文正文是题库，不能为了好看改写。

方法来自 Damir Sokolovsky 的 unslop（[@heydamir](https://x.com/heydamir)，[仓库](https://github.com/heydamir/unslop)，CC BY 4.0）。

## Decision

整页按考场书桌来排。表面是石墨中性色。`#1f46a5` 只出现在「开始自测」和当前概念节点的边线上。`#9f2d2d` 只出现在两处：正在看的目录项左边，以及揭晓后答案的左边。`#157a45` 只标已掌握。

刊头是短的。标题是「对话题库复习」，旁边一句说明、一行计数、开始自测和今日复习。第一屏的画面是这道真题本身。轨道图、英文眉题和四张指标卡都去掉了。登录后的工作台用同一条刊头，并保留退出。

九遍都落在 `src/styles.css`、`src/body.html`、`src/controller.js`，以及 `apps/web` 的样式、`study-page.tsx`、`question-card.tsx`、`sign-in-page.tsx`。`dist/` 与静态源码一致。间距走 4 的步长。按钮上的记号去掉。搜索是「搜索」。揭晓前，概念要点、未揭晓的各空答案和第三、第四区都不显示。多空可以按空揭晓，见 [费曼门槛、换空和按空揭晓](./2026-11-01-feynman-blank-focus.md)。论文仍是一栏阅读。宋体用于刊头、题目标题和论文。界面字重是 400 和 500。没有入场飞入，悬停只换表面色，按下缩到 0.98。窄屏不显示「顶部」，避免挡住题干。

## Alternatives considered

把登录后的工作台留成一条更短的学习顶栏，静态页单独做刊头。两张脸会再次分开。确认的是两边都用短刊头，视觉是真题。

另做一张插画或生成图放在刊头旁边。方向要的画面就是这道题。这一轮也不做付费生图。

只改 React，不动 Sites 上的 `dist/`。部署出去的仍是旧的轨道图。

## Consequences

题干、选项、解析、口诀、论文段落和资料依据保持题库原句。界面层改的是按钮、占位、模式名和揭晓前的遮挡。

`packages/bank-architecture` 和 `src/data.js` 没有改。掌握等级、间隔和笔记长度仍由原来的规则计算。

登录错误用同一种红。它和笔迹是同一个色值，因为这一套里只有一种红。

静态页和 React 各有一份题目渲染。这次两边的遮挡、按钮和刊头一起改了。只改一边时，遮挡会再次漏出答案。

视觉事实写在 [界面规格](../../../../openspec/specs/ui-design/design.md)。
