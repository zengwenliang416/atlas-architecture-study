# Agent Note: 费曼门槛、换空和按空揭晓

Status: implemented

## Problem

「今天复习完」在三问都空着时仍可按下。焦点模式不能在多空之间移动，完成快捷键也不看这道题有没有揭晓。多空题只有整卡「揭晓答案」，选定一空之后要么看见每一空的答案，要么这一空也仍被整卡遮住。

## Decision

至少一槽费曼笔记去掉空白后还有文字，「今天复习完」才可点。按钮旁一行红线旁注写明原因。不要求三槽都写，不按字数给分，也不做模型批改。没有「仍要完成」之类的旁路：那要多一个控件和一套确认状态，并不省事。整卡讲解仍只来自「揭晓答案」，展开全部题目不揭晓。多空题在选定该空之后，可以用「揭晓此空」和「遮挡此空」只打开或遮住这一空的对错和答案；没有选项的空可以直接揭晓。其它空和第三、第四区保持遮住。揭晓集合只留在页面里，不写入 `study_record`，完成请求仍不带揭晓字段。

焦点模式保留方向键、1 到 4 和 Enter。方括号在多空题上切换当前空。`c` 只在整卡已经揭晓后标记完成，并且仍要过费曼门槛。按键写在原有的一行提示里。不另做浮层或命令面板。宽度不超过 720px 时，底栏仍只数当前筛选列表，选项不被新的浮层盖住。

静态页和登录后的复习台用同一套规则。语义写在 [静态站点](../../../../docs/subsystems/static-site.md)，复习台从 [Web](../../../../docs/subsystems/web.md) 链过去。整卡揭晓和窄屏底栏见 [考场揭晓和上海日历两边对齐](../bug-fix/2026-11-01-exam-desk-semantics.md)。红线旁注沿用 [复习界面按考场方向收束](./2026-11-01-unslop-direction.md) 的笔色，不铺黄底。

## Alternatives considered

加一颗「仍要完成」。旁路要记住用户是否确认过，桌面上会多一个动作。这一轮不放。

三槽都要写、设最短字数，或把笔记交给模型打分。门槛会变成字数游戏，也越出界面。

用浮层列出全部快捷键。窄屏上会盖住选项。现有的一行提示够用。

点选选项或展开全部题目时自动揭晓。点选只记下选择；展开只列出卡片。没有选项的空无法「选定」，所以该空可以直接揭晓。

把揭晓写进学习记录或完成请求。间隔和笔记长度仍由原来的规则计算，揭晓继续只活在这一页。

## Consequences

`packages/bank-architecture` 和 `src/data.js` 没有改。完成接口的请求体仍是空对象。`tests/startup.mjs` 检查空笔记按不动、只写一槽就能按、方括号换空、揭晓前 `c` 不完成、揭晓后 `c` 才完成、单空揭晓不带出其它空和讲解，以及底栏仍显示筛选后的题号。窄屏不新增固定浮层。静态站点页同时写下揭晓、门槛和按键，字数上限是 242，正文留下 5% 余量。
